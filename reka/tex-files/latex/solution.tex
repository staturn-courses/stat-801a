\item $\mathbf{[13pts.]}$ \textbf{Sunflower seedlings.} A biologist was interested in determining whether sunflower seedlings treated with an extract from \textit{Vinca minor} roots resulted in a lower average height of sunflower seedlings than the standard height of 15.7 cm. The biologist treated a random sample of 33 seedlings with the extract and subsequently measured the height of those seedlings. The data can be found in the file \emph{Height.jmp} on Blackboard.

\begin{enumerate}
\item  Using SA, R, JMP, or Excel find the values of the mean and the standard deviation for these data. Round your answers to two decimal places.\\
$$\red{\bar{x} =  \underline{15.41}   \hspace{1in}  s = \underline{0.42}}$$
\item  At the 0.01 level of significance, is there evidence that the true average height of the seedlings treated with an extract from \textit{Vinca minor} roots is less than 15.7 cm?
\begin{enumerate}
\item  Identify the null and alternative hypothesis, $H_0$ and $H_a$:
$$\red{H_0: \mu = 15.7 \qquad \hbox{vs} \qquad H_A: \mu < 15.7}$$

\item  Report the test statistic. $\red{t = -3.99}$
\item  How many degrees of freedom are associated with your test statistic? $\red{df = 32}$
\item  Report the appropriate $p$-value. $\red{p = 0.0002}$
\item  Identify the appropriate decision. 
\begin{itemize}
	\item \red{Since the $p$-value is less than $\alpha$ = 0.01, we reject the null hypothesis.}
	\item Since the $p$-value is greater than $\alpha$ = 0.01, we reject the null hypothesis.
	\item Since the $p$-value is less than $\alpha$ = 0.01, we fail to reject the null hypothesis.
	\item Since the $p$-value is greater than $\alpha$ = 0.01, we fail to reject the null hypothesis.
\end{itemize}
\item  Based on your decision, write a conclusion in the context of the problem.\\
\red{There is statistically significant evidence at the $\alpha=0.01$ level to indicate that the sunflower seedlings treated with an extract from \textit{Vinca minor} roots resulted in a lower average height of sunflower seedlings than the standard height of 15.7 cm.}

\end{enumerate}
\item  Explain what a Type I Error is in the context of this problem. \\
\red{A Type I error in this situation is concluding that the true average height of the seedlings treated with an extract from \textit{Vinca minor} roots is less than 15.7 cm when in reality it is not.}


%\blue{}
\end{enumerate}
